# data_sample

Input data for the bundled sample: the 3 × 3 half meshes around
Shimokitazawa (`study_area_meshes.csv`). Every file keeps the column layout of
its original source, so a full dataset can replace it without code changes.
Generated by [`tools/make_data_sample.py`](../tools/make_data_sample.py).

* **real**: rows of the open dataset, clipped to the study area.
* **synthetic**: invented rows with the original columns. They are placed inside
  the study area but are not real places, people or trips.

Shapefile sources are stored as GeoJSON (EPSG:4326) for readability. The
loaders read either format.

## What the synthetic files exercise

* **Zenrin**: one POI written as two rows with different BUSC codes, which are
  grouped into one POI with two categories. One transport row (PTYPE 22) is
  dropped. BUSC codes cover all 14 categories, including the
  Shopping / Life_related overlap. Addresses use real town / chōme names with
  invented block numbers. Names and phone numbers are placeholders.
* **OD**: pairs with meshes outside the study area, which are filtered out.
* **Trips / survey**: a respondent without sex (no group), a trip of a user
  missing from the survey (ignored), the purpose alias `Dining` (→ `Eating`),
  and destinations outside the study area.

## Attribution

Before publishing, check each provider's current terms. The open datasets
usually require an attribution such as:

* 出典：国土数値情報（行政区域データ、学校データ、土地利用細分メッシュデータ、500mメッシュ別将来推計人口データ）（国土交通省）を加工して作成
* 出典：政府統計の総合窓口(e-Stat) 境界データ（総務省統計局）を加工して作成
* 鉄道LOD (https://uedayou.net/jrslod/)

The railway line and station files were derived from national railway data and
the railway LOD in the GUFM project. Confirm their provenance and license.
